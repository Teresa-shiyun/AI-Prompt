# AI Prompt Workspace Frontend / 前端说明

## Overview / 简介

This folder contains the Next.js frontend for the AI Prompt Workspace prototype. The current UI uses mock data from `src/lib/mock-data.ts`.

这个目录是 AI Prompt Workspace 的 Next.js 前端。当前界面使用 `src/lib/mock-data.ts` 中的 mock data 展示 Prompt 管理、评估和版本对比流程。

## How to Run / 本地运行

```bash
npm install
npm run dev
```

Open <http://localhost:3000>.

运行后打开 <http://localhost:3000>。更完整的项目状态、限制和后续计划请查看根目录 [README](../README.md)。
